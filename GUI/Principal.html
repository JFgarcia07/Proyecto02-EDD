Catálogo de Supermercado

Estructura de Datos

El Sistema de Gestión de Catálogo de Productos de Supermercado es una aplicación web que permite gestionar el inventario de productos distribuidos en múltiples sucursales interconectadas. El sistema integra diversas estructuras de datos implementadas desde cero.

Flujo de uso recomendado

El orden correcto para utilizar el sistema es el siguiente:

  1. Cargar CSV de sucursales — sin sucursales no se pueden agregar productos.
  2. Cargar CSV de conexiones — define las rutas entre sucursales para Dijkstra.
  3. Cargar CSV de productos — mínimo 1000 productos según el proyecto.
  4. Gestionar productos — agregar, buscar, eliminar y hacer rollback.
  5. Transferir productos — el sistema calcula la ruta óptima con Dijkstra.
  6. Visualizar estructuras — ver árboles, hash y grafo, descargar .dot y .png.
  7. Analizar rendimiento — ejecutar benchmark y comparar estructuras.
